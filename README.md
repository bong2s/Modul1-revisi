## Instalasi dan menjalankan (GARML Modul 1 — AR)

Prasyarat: Node.js 18+ dan npm.

```bash
npm install          # atau: npm ci
npm run dev          # mode pengembangan (http://localhost:5173)
npm run typecheck    # pemeriksaan TypeScript
npm run build        # build produksi ke folder dist/
npm run preview      # menjalankan hasil build
```

Kamera memerlukan HTTPS atau localhost. Model 3D berada di `public/models/`;
lihat `public/models/README-MODEL.txt` untuk file model yang harus dilengkapi.
Catatan revisi dan keterbatasan aset: `REVISI_MODUL1_AR.md`.
